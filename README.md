## Проект

Реализован макет «Поиск предметов».

В проекте доступны:

- вводный экран и модальное описание первого уровня;
- поиск трех предметов на интерактивной карте;
- прогресс-бар с анимацией кота;
- увеличение и перемещение карты;
- список найденных предметов и popup с найденным предметом;
- форма с валидацией обязательных полей;
- состояния формы: загрузка, успешная отправка, повторное получение бонусов и ошибка;
- финальный экран «Игра завершена».

## Технологический стек

Чистые HTML/CSS/JS, без фреймворков и сборщиков.

## Запуск

Распаковать архив локально, открыть файл index.html в браузере.

Проект не требует установки зависимостей, сборки или запуска backend-сервера.

## Адаптивность

Предусмотрены брейкпоинты `1200px` и `320px`, а также промежуточные состояния для планшетов и мобильных устройств. На мобильных устройствах игровое поле сохраняет пропорции и доступно для горизонтальной прокрутки.

## Логика отправки формы

Отправка формы в текущей демонстрационной версии имитируется на клиенте: после валидации показывается loader на 3 секунды, затем открывается модальное окно с результатом. Состояние ошибки предусмотрено для подключения ответа backend/API.
